Set up your server

This app runs a private Final Fantasy XI server (LandSandBoat) and its database in Docker.

The database, settings and navmeshes go here. If this folder already has a server set up (a .env file), the app uses it as it is.

Players on other computers need this computer's LAN or VPN address. Detect automatically picks the LAN address again on every start.

      Without Tailscale: port forwarding
      
      
      Players can also connect over the internet to your network's public (WAN) address. Nothing needs installing, but your router has to forward the server's ports to this computer, and anyone on the internet can then reach them.
      
      
      
        
      
          Look up this network's public address
          
      Looked up with an outside service (ipify, with icanhazip and Amazon as fallbacks). To use a fixed address instead, such as a dynamic DNS one's, type it in Settings.
      
        
      
        
        
      
      
      
      
        
      
          On your router, forward these ports to 
          
      TCP 54001, 54002, 54230 and 54231, and UDP 54230. Look for Port forwarding or Virtual server in the router's settings, and give this computer a fixed LAN address there so the forwarding keeps pointing at it.
      
          
      The game sends every player the public address, so players on your own network, and the game on this computer, only get into the world if the router supports NAT loopback (hairpin NAT). If your router's own WAN address differs from the one above, your internet provider uses CGNAT and forwarding can't work; use Tailscale instead.

      Game masters
      
      
      GM levels belong to characters: pick a level for each character that should have GM commands such as !goto or !additem. Level 5 can use every command. A character in game gets the new level the next time it zones or logs in. The database has to be running, so start the server first.
      
      
      
      
        
    
        
  
        

  
  
        
    
        
      
        Auction house bot
        
      
        The bot (ffxiahbot) buys what players put up for sale and keeps the auction house stocked, at prices taken from retail. It runs beside the server and starts and stops with it.
        
      
        
        
        
          
          
        The first start downloads it (about 110 MB).
        
        
        
        
      
        
      
        
        
        
          
          
        Shown as the seller of its items and the buyer of yours. Up to 15 characters.
        
        
        
        
      
        
      
        
        
        
          
          
        Keeps every item on the price list in stock.
        
        
        
        
      
        
      
        
        
        
          
          
        Buys an item a player lists at or below the price list's price.
        
        
        
        
      
        
      
        
        
        
          
        
        
        
        seconds
        
      
        
      
        
        
        
          
          
        It also stocks when it starts.
        
        
        
        
        minutes
        
      
        
      
        
        
        
          
          
        Retail prices can be below what NPCs pay for an item, which lets players make gil by buying from the bot and selling to an NPC; the level 75 list has fewer such items than the full one. Your own list is items.csv in the bot's folder, made from the level 75 list the first time; edit it in a spreadsheet.

          Stock the auction house
          
        Tops up every item on the price list without waiting for the next restock. The server has to be running.
        
        
        
        
      
        
      
        
        
        
          Take the bot's items down
          
        Removes everything the bot is selling. Players' own listings stay. While the bot runs it stocks again at the next restock.
