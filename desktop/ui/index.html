Set up your server

This app runs a private Final Fantasy XI server (LandSandBoat) and its database in Docker.

The database, settings and navmeshes go here. If this folder already has a server set up (a .env file), the app uses it as it is.

Players on other computers need this computer's LAN or VPN address. Detect automatically picks the LAN address again on every start.

    Game client

    A native Final Fantasy XI client for LandSandBoat servers, for Linux and Windows.

    Its other parts must sit beside it. Installing unpacks the game into the client folder, with a temporary copy beside it while it works, so that drive needs room for both. It takes a while.

    Create your account on the client's login screen (Create account), then log in.
