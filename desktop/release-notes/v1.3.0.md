What's new in 1.3.0

- New Website screen: turn on the server's own website, choose who can reach it, and open the admin panel already signed in. Players sign in with their game account and see their own account and characters.
- Admin panel (server owner and game masters): list and search accounts and characters, ban and unban (timed bans lift themselves), reset passwords and two-step sign-in, change a game master's level, and read the action log.
- Public pages: a home page with news and rules the owner edits in the browser, who's online, and rankings (level, job, crafting, play time). Hidden and anonymous characters are never listed.
- Sign-up page: visitors create a game account on the site while the server allows account creation. Invite codes are required by default; the owner makes and revokes them in the admin panel.
- Optional HTTPS: a Caddy proxy puts the website on the internet with its own certificate, and an optional Cloudflare DNS updater keeps the address current. Both stay off until you turn them on.
- Sign-in is rate limited and hardened against password guessing, and the website uses its own database password. Existing servers get it added at the next start.
