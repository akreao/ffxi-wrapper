What's new in 1.4.0

- Sign-up is closed by default after you update. Open it again on the Invite codes page of the admin panel when you want new players to join. Invite codes still apply while it's open.
- Game masters are managed on the website only. Change a game master's level on the admin panel's Characters page (it has a Game masters only switch). The app's Game masters screen is now a read-only list with a button that opens the website.
- Website roles: an account's role on the website is separate from its in-game game master level.
- New website pages: Item database (search every item and see its details), Audit logs (what players bought, sold, traded and searched, with who did what), Give item (the owner can give a player an item from the item database), Auction house (read-only listings, sale history and prices), and a Help desk page for game master calls.
- The owner link opens the admin panel on 127.0.0.1 so it works without port forwarding. Turning the website off also turns off its public address and dynamic DNS updater. A website port that isn't valid is cleared.
- Play with friends is split into Tailscale and Port forwarding tabs. The app polls less often in the tray and batches log lines, so it uses less CPU.
- The game client and server pins moved to the latest versions of the fork, including the one-time Destrier Beret and Chocobo Shirt grant for collector's edition accounts.
- The README is shorter, and the long sections moved to docs/ in plainer English.

Full changelog: https://github.com/akreao/ffxi-wrapper/compare/v1.3.0...v1.4.0
