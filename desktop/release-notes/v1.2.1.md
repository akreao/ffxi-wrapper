What's new in 1.2.1

- The server and the game client move to the November 2026 retail update (30261102_0) together. New installs and app-pinned servers pick up the new LandSandBoat build, with the new Trust Ascension packets and the shifted NPC and text ids.
- Patch the game to 30261102_0 before logging in to the updated server (the client's Update window does it). The server refuses older clients.
- A server folder that still holds the app's previous LandSandBoat pin follows the new one automatically. A commit you typed in yourself is left alone.
