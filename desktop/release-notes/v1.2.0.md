What's new in 1.2.0

- The game client now uses vana-client's xiloader 3.0 and connects to the lobby over TLS, as the updated LandSandBoat server requires. Fresh installs can start the login server again.
- The app now pins its own login server's certificate the way vana-client expects (by its public key). Before, vana-client couldn't read the pin file, set it aside on every start, and lost any other servers' pins in it. The fingerprint under Play with friends now gives friends the right hash.
- Scrolling on Game client > Settings is smooth again.
- For maintainers: a script that moves the LSB and vana-client pins together (scripts/bump-pins.py), and a Checks workflow for pins, compose.yaml, scripts and workflows.

Full changelog: https://github.com/akreao/ffxi-wrapper/compare/v1.1.1...v1.2.0
